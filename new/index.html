Niord Documentation

Guides for Niord, the system for Navigational Warnings and Notices to Mariners

Welcome to the Niord documentation

Niord is an open-source system for maritime safety information. Editors write, publish and promulgate Navigational Warnings and Notices to Mariners in its administration application, and mariners read them on its public site. The organisation behind Niord is the Danish Emergency Management Agency.

The guides on this site describe the current version of Niord: one base product that every country runs, with a thin layer of its own for each country's languages, look and data.

New to this version?

  • What changed since the old Niord (pdf): for those who know the earlier Niord, what is new, what has moved and what is gone.

User manuals

  • User Manual for Editors (pdf): writing, verifying and publishing messages.
  • User Manual for Admins (pdf): the data editors work with, such as areas, charts, sources, publications, users and mailing lists.
  • User Manual for Sysadmins (pdf): setting up and running a deployment, from domains and message series to templates, reports and settings.

For mariners

  • The public site (pdf): finding, reading and printing the warnings and notices, on a list or a map, and downloading the publications.

Integration

  • Niord Public API (pdf): the public REST interface that other systems read messages and publications from.
  • Niord Model (pdf): the message model, Niord's main interchange format.
  • Niord Message Presentation (pdf): guidelines for how a client presents Niord messages.

Developers and countries

  • Developer Guide (Niord v4) (pdf): how the system is built, how to run it on your own machine, and how to change it.
  • Country kit guides: how a country's deployment is built on the base product, with the guides for its designers and operators. The guides for the people who build a country are listed there and ship in the country kit package.
